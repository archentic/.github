# Archentic

Archentic is a private addon set on a shared runtime. [framework](https://github.com/archentic/framework) is the substrate: generic runtime containers with addons on top. The repositories below are private; organization members can open the links.

## Runtime

- [framework](https://github.com/archentic/framework) — Substrate for agentic coding. Generic runtime containers with addons on top.
- [dashboard](https://github.com/archentic/dashboard) — Operator dashboard for addon-contributed widgets, with system and user visibility preferences.
- [sandbox](https://github.com/archentic/sandbox) — Demo pages, widgets, and navigation for framework section and widget contracts.
- [extra_themes](https://github.com/archentic/extra_themes) — Optional UI themes (Monokai, Darcula) registered through the themes contract.

## People

- [profile](https://github.com/archentic/profile) — User profile page, hero media, avatars, details, privacy, and social links.
- [friends](https://github.com/archentic/friends) — Friend requests, a friends list, and profile friendship actions.
- [achievements](https://github.com/archentic/achievements) — Unlockable achievements, criteria, and achievement points.
- [bonus_points](https://github.com/archentic/bonus_points) — Bonus-point balances, an earn and spend ledger, a redeem store, and peer transfers.

## Chat

- [chat](https://github.com/archentic/chat) — Site chat and direct messages, with reusable channels and realtime events.
- [stream](https://github.com/archentic/stream) — One shared player page with chat.

## Media

- [media](https://github.com/archentic/media) — Media navigation and shared Media system settings. Feature addons depend on this hub.
- [media_library](https://github.com/archentic/media_library) — Browse synced catalogs: home hubs, libraries, playlists, items, and people.
- [media_imports](https://github.com/archentic/media_imports) — Resolve share and watch URLs into ordered media URLs.
- [media_player](https://github.com/archentic/media_player) — Watch surface. Local mode uses the active Plex session; remote mode plays a configured live source.
- [media_relay](https://github.com/archentic/media_relay) — Local and remote playback control, play queues, and library chrome.
- [plex](https://github.com/archentic/plex) — Plex Media Server connector and local catalog mirror.
- [plex_auth](https://github.com/archentic/plex_auth) — Plex.tv credentials for the Plex connector.
- [jellyfin](https://github.com/archentic/jellyfin) — Jellyfin connector and local catalog mirror.
- [jellyfin_auth](https://github.com/archentic/jellyfin_auth) — Jellyfin server credentials.
- [broadcasts](https://github.com/archentic/broadcasts) — Per-user live channels: RTMP ingest, a public watch page, and live status.
- [ffmpeg](https://github.com/archentic/ffmpeg) — Worker jobs for HLS, MPEG-DASH, and optional RTMP publish.
- [rtmp](https://github.com/archentic/rtmp) — RTMP publish helpers for playback addons.
- [spotify](https://github.com/archentic/spotify) — Spotify OAuth connector and Web Playback access tokens.

## AI

- [rag](https://github.com/archentic/rag) — Retrieval workspaces, vector storage, ingestion jobs, and RAG MCP wiring.
- [openrouter](https://github.com/archentic/openrouter) — OpenRouter model listings and a cost-effectiveness recommendation.
- [openrouter_auth](https://github.com/archentic/openrouter_auth) — OpenRouter credentials.

## External services

- [github](https://github.com/archentic/github) — Pull request and Actions screens, plus repository sync.
- [github_auth](https://github.com/archentic/github_auth) — GitHub credentials for the GitHub addon.
- [google](https://github.com/archentic/google) — Google Drive folder catalog and sync screens.
- [google_auth](https://github.com/archentic/google_auth) — Google credentials for Drive and login.
- [atlassian](https://github.com/archentic/atlassian) — Jira board and Confluence viewer screens.
- [atlassian_auth](https://github.com/archentic/atlassian_auth) — Atlassian Cloud credentials.
- [x_auth](https://github.com/archentic/x_auth) — X (Twitter) credentials and login.
